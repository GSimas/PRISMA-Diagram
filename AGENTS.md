# AGENTS.md

- Trabalhe na aplicação dentro de `web/`; mantenha `netlify.toml` e a documentação na raiz.
- Preserve o princípio local-first: nenhuma contagem científica deve sair do navegador sem ação explícita.
- Não altere fórmulas, unidades (`record`, `report`, `study`) ou modelos PRISMA sem fonte primária e testes.
- Toda nova string visível precisa de tradução nos seis locales ou de uma justificativa documentada.
- Use `pnpm lint`, `pnpm typecheck`, `pnpm test` e `pnpm build` antes de entregar.
- Não versione `node_modules`, `dist`, relatórios de teste, caches, dados de usuário ou segredos.
- Materiais PRISMA 2020 são CC BY 4.0; o código do projeto é MIT. Preserve atribuições e independência institucional.
